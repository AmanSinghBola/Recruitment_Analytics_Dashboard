
# Recruitment Analytics Dashboard | Power BI

## Project Overview

A recruitment analytics dashboard developed using Microsoft Power BI to analyse candidate pipelines, recruitment outcomes and hiring performance.

The dashboard provides an overview of recruitment activity and allows users to explore hiring metrics across departments, recruiters and candidate sources.

## Technologies Used

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data visualisation
- Data cleaning and validation

## Key Performance Indicators

| KPI | Value |
|---|---:|
| Total Candidates | 40 |
| Active Candidates | 24 |
| Hired Candidates | 8 |
| Rejected Candidates | 8 |

## Dashboard Features

- KPI cards showing candidate totals and recruitment outcomes.
- Candidate distribution by recruitment stage.
- Hires by department and recruiter.
- Hires by recruitment source.
- Average time to hire.
- Interactive department slicer for filtering results.

## Key Insights

- Employee referrals achieved a 100% hire rate within the sample dataset.
- LinkedIn candidates achieved a 20% hire rate within the sample dataset.
- Recruitment performance can be explored across departments and candidate sources.

These findings describe the assessment dataset and should not be generalised to wider recruitment activity.

## DAX and Data Analysis

Created DAX measures to calculate candidate totals, active candidates, hires, rejections, hire rates and average time to hire.

## Limitations

- Recruitment stages represent each candidate's current status rather than a complete historical funnel.
- The dataset is relatively small, limiting broader conclusions.
- Additional stage-history data would enable more detailed conversion analysis.

## Future Improvements

- Stage-to-stage conversion rates.
- Time to hire by department and role.
- Rejection and withdrawal reason analysis.
- More detailed recruiter performance reporting.
